**Endpoint**

```
https://sandbox.safaricom.co.ke/v1/KYC-validation/validateID
```

## Overview

Validates a phone number in real time against two parameters: **ID Type** (National ID, Military ID, or Passport) and **ID Number**. Returns a boolean: whether the registration on that number matches the identity details supplied.

## How it works

1. The partner sends the mobile number, ID type, and ID number.
2. The API checks the number against Safaricom's records for that identity.
3. It returns `true` if they match, `false` if they don't.
4. The partner proceeds with onboarding, authentication, or fraud checks based on the result.

## Request

```json
{
  "requestRefID": "{{$timestamp}}",
  "shortCode": "12345",
  "msisdn": "254710860780",
  "idType": "01",
  "idNumber": "454353453"
}
```

| Field | Description | Sample value |
|---|---|---|
| `requestRefID` | Unique string per request, generated by your system. | `83a2-4b44-aaffcb3f93` |
| `shortCode` | Your Pay Bill/Till number. | `776700` |
| `msisdn` | Number to validate, `254XXXXXXXXX`. | `254722000000` |
| `idType` | `01` National ID, `02` Military ID, `05` Passport. | `01` |
| `idNumber` | The customer's ID number. | `45435345` |

## Response

<Callout type="info">
This API is **synchronous**: the match result comes back directly in the response, not via a callback.
</Callout>

Match:

```json
{
  "responseRefID": "1771929697",
  "responseCode": "4000",
  "responseMessage": "Details match successfully",
  "status": "true"
}
```

Mismatch:

```json
{
  "responseRefID": "1771929733",
  "responseCode": "4001",
  "responseMessage": "Details do not match",
  "status": "false"
}
```

## Error codes

```json
{ "responseId": "83a2-aa8bfffcb3f939", "errorCode": "403.001", "errorMessage": "subscription_not_available" }
```

```json
{ "requestId": "a078-4d57-9460-b5782b2dcde913", "errorCode": "400", "errorMessage": "Bad Request - Invalid MSISDN, the value is required and start with 2547xx and contain digits only" }
```

| Code | Meaning |
|---|---|
| `403.001` | Subscription not available |
| `400` | Bad request, invalid MSISDN format |
| `401.001` | Invalid access token |
| `500` | Invalid parameter input |

## Testing

Safaricom's own testing instructions for this page say to "select transaction status product" when creating a test app, which is the setup for the [Transaction Status](/daraja/transaction-status) API, not Mobile Number Validation.
