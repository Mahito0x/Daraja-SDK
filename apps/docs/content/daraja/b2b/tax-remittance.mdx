**Endpoint**

```
https://sandbox.safaricom.co.ke/mpesa/b2b/v1/remittax
```

## Overview

Remits tax to KRA in real time. Using this API requires prior integration with KRA itself for tax declaration and generation of a **Payment Registration Number (PRN)**, since the PRN is what identifies which tax obligation the payment settles.

<Callout type="info">
Unlike the rest of the B2B family, this uses its own `/remittax` path rather than the shared `/mpesa/b2b/v1/paymentrequest` endpoint used by [Business Pay Bill](/daraja/business-paybill) and [Business Buy Goods](/daraja/business-buy-goods).
</Callout>

## Request

```json
{
  "Initiator": "TaxPayer",
  "SecurityCredential": "FKXl/KPzT8hFOnozI+unz7mXDgTRbrlrZ+C1Vblxpbz7jliLAFa0E/…../uO4gzUkABQuCxAeq+0Hd0A==",
  "Command ID": "PayTaxToKRA",
  "SenderIdentifierType": "4",
  "RecieverIdentifierType": "4",
  "Amount": "239",
  "PartyA": "888880",
  "PartyB": "572572",
  "AccountReference": "353353",
  "Remarks": "OK",
  "QueueTimeOutURL": "https://mydomain.com/b2b/remittax/queue/",
  "ResultURL": "https://mydomain.com/b2b/remittax/result/"
}
```

<Callout type="warn" title="Defect in the source material">
Two things carried directly from Safaricom's own sample. First, the field is written `"Command ID"` with a space, rather than `CommandID` as used in the parameter table below it, the same inconsistency documented on [Business Pay Bill](/daraja/business-paybill). Second, the sample has a trailing comma after the `ResultURL` value, which makes it invalid JSON as published; it's removed above.
</Callout>

| Field | Description | Sample value |
|---|---|---|
| `CommandID` | Only `PayTaxToKRA` for this API. | `PayTaxToKRA` |
| `Initiator` | API operator username. | Username |
| `SecurityCredential` | Encrypted initiator password. | (encrypted string) |
| `PartyA` | Your own short code, debited. | `123454` |
| `SenderIdentifierType` | Only `4` is allowed. | `4` |
| `PartyB` | Only `572572` is documented as valid for this use case, KRA's collection account. | `572572` |
| `RecieverIdentifierType` (sic) | Only `4` is allowed. | `4` |
| `Amount` | Transaction amount. | `3000` |
| `AccountReference` | The PRN issued by KRA. | `PRN1234XN` |
| `Remarks` | Up to 100 characters. | Free text |
| `QueueTimeOutURL` / `ResultURL` | Timeout and result callback URLs. | `https://domain:port/path` |

<Callout type="warn" title="Defect in the source material">

Reformatted above into valid JSON with the same field names and values.
</Callout>

## Unsuccessful result callback

Same shape as the [Business Pay Bill](/daraja/business-paybill) unsuccessful callback: `ResultCode` `2001` with `ResultDesc` "The initiator information is invalid" is the documented sample.
